# ADR 0002: 클라우드 AI 처리

- 상태: 승인됨
- 날짜: 2026-07-19

## 맥락

전사, 화자 분리, 노이즈 억제, 노트 생성은 모바일 브라우저에서 안정적으로 실행하기 무거우며, iPhone Safari의 리소스와 백그라운드 제약도 고려해야 한다.

## 결정

PWA는 녹음·청크 업로드·상태 표시를 담당하고, 무거운 음성인식과 화자 처리 모델은 클라우드 워커에서 실행한다. 초기에는 실제 AI API 대신 mock adapter를 사용한다.

## 결과

- 클라이언트 번들·배터리·기기 성능 의존도를 낮춘다.
- 서버 측 키 관리와 민감 데이터 보호 정책이 필요하다.
- 실제 공급자 adapter는 품질, 비용, 개인정보 요구사항 검토 후 추가한다.
