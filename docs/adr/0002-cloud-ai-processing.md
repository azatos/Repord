# ADR 0002: 클라우드 AI 처리

- 상태: 승인됨
- 날짜: 2026-07-19

## 맥락

전사, 화자 분리, 노이즈 억제, 노트 생성은 모바일 브라우저에서 안정적으로 실행하기 무거우며, iPhone Safari의 리소스와 백그라운드 제약도 고려해야 한다. 클라우드 처리는 실제 음성과 결과물을 다루므로 접근 제어와 수명주기 보호도 필요하다.

## 결정

PWA는 녹음·청크 업로드·상태 표시를 담당하고, 무거운 음성인식과 화자 처리 모델은 클라우드 워커에서 실행한다. 초기에는 실제 AI API 대신 mock adapter를 사용한다. 실제 오디오 업로드는 인증된 소유자 범위 접근, 비공개 저장소, 만료 및 연쇄 삭제가 구현된 뒤에만 허용한다. 그 전에는 합성 또는 익명화된 테스트 오디오만 사용한다.

## 결과

- 클라이언트 번들·배터리·기기 성능 의존도를 낮춘다.
- 처리 서비스는 최소 권한으로 세션 데이터에 접근하고, 오디오·전사문·노트·서명된 저장소 URL을 로그에 기록하지 않아야 한다.
- 성공 처리된 원시 청크와 임시 AI 산출물은 24시간 안에 삭제하고, 실패/중단 세션 청크는 마지막 활동 후 24시간 안에 삭제한다.
- 실제 공급자 adapter는 품질, 비용, 개인정보 요구사항 검토 후 추가한다.
