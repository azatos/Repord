# ADR 0003: iOS 백그라운드 녹음 제한을 제품 제약으로 취급

- 상태: 승인됨
- 날짜: 2026-07-19

## 맥락

iOS Safari에서 PWA가 백그라운드 또는 화면 잠금 상태에서도 마이크 녹음을 지속할 것이라고 신뢰성 있게 보장할 수 없다. 이 제약을 숨기면 사용자는 누락된 강의 기록을 완전한 기록으로 오인할 수 있다.

## 결정

화면을 켜 둔 포그라운드 녹음을 기본 방식으로 한다. 관찰 가능한 연속 청크는 `observed-continuous`로 기록한다. MediaStream 종료, 청크 도착 지연, 시간 범위 단절처럼 공백을 입증하는 신호가 있으면 `confirmed-gap`으로 기록하고 경고와 추정 시간 범위를 표시한다. Safari가 중단되어 관찰 신호를 얻을 수 없으면 `continuity-unknown`으로 기록하고, UI는 녹음 완전성을 검증할 수 없다고 경고한다. 실제 동작은 지원 대상 iPhone Safari에서 반복 검증한다.

## 결과

- 백그라운드 연속 녹음을 기능 약속이나 출시 기준으로 삼지 않는다.
- `confirmed-gap`만 확인된 공백을 의미하며, `continuity-unknown`은 연속 녹음을 주장하지 않는다.
- 관찰이 불가능한 경우를 포함해 모든 공백을 완벽히 식별한다고 주장하지 않는다.
- 사용자는 기록의 불확실한 구간을 확인할 수 있고, 지원 범위는 기기 테스트 결과로 관리한다.
