# ADR 0001: PWA 우선 접근

- 상태: 승인됨
- 날짜: 2026-07-19

## 맥락

Repord는 iPhone Safari에서 설치해 사용하는 강의 녹음 경험이 필요하지만 Apple Developer 구독과 네이티브 iOS 배포를 전제할 수 없다.

## 결정

설치 가능한 웹 앱(PWA)을 첫 번째 클라이언트로 선택한다. 핵심 녹음 흐름은 화면을 켠 포그라운드 사용을 기본으로 설계하며, 설치·권한·녹음 동작은 실제 iPhone Safari에서 검증한다.

## 결과

- Apple Developer 구독 없이 웹 배포와 반복 검증을 시작할 수 있다.
- 네이티브 앱 전용 백그라운드 권한/동작을 기대하지 않는다.
- Safari별 제약은 제품 안내와 테스트 계획에 명시해야 한다.
