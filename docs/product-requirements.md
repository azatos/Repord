# 제품 요구사항

## 1. 목적

Repord는 iPhone Safari에서 설치해 쓰는 강의 녹음 및 강의노트 생성 PWA다. 강의 중 녹음한 음성을 클라우드로 전송해 전사하고, 강사와 사용자가 허용한 발화자를 우선 반영하여 강의 종료 후 구조화된 노트를 만든다.

## 2. 대상 사용자와 핵심 흐름

1. 사용자는 iPhone Safari에서 앱을 설치하거나 열고 마이크 권한을 허용한다.
2. 사용자는 강의 세션을 시작하고, 화면을 켠 포그라운드 상태로 녹음한다.
3. 앱은 녹음 상태와 업로드/전사 진행 상태를 보여 준다.
4. 앱은 관찰 가능한 공백이면 `confirmed-gap`과 경고·추정 구간을, Safari 중단으로 관찰할 수 없으면 `continuity-unknown`과 완전성을 검증할 수 없다는 경고를 표시한다.
5. 강의가 끝나면 사용자는 세션을 종료한다.
6. 클라우드는 전사와 화자 필터링을 처리하고 구조화된 강의노트를 반환한다.

## 3. 기능 요구사항

### 녹음과 PWA

- iPhone Safari에서 설치 가능한 PWA 경험을 목표로 한다.
- 녹음의 기본 방식은 화면을 켜 둔 포그라운드 녹음이다.
- 앱은 녹음 시작 전 iOS Safari가 백그라운드에서 마이크 녹음을 지속한다고 보장할 수 없음을 명시한다.
- 녹음 세션은 전송 가능한 청크로 나누고, 각 청크의 순서와 녹음 시간 범위를 보존한다.
- 관찰 가능한 연속 청크는 `observed-continuous`로, MediaStream 종료·시간 범위 단절 등으로 확인된 공백은 `confirmed-gap`으로 기록한다. `confirmed-gap`에는 경고와 추정 시간 범위를 표시한다.
- Safari가 중단되어 관찰 신호를 얻을 수 없으면 `continuity-unknown`으로 기록하고, UI는 녹음 완전성을 검증할 수 없다고 경고한다. 이 상태를 연속 녹음으로 표시하지 않는다.

### 전사·화자·노트

- 전사는 실시간 또는 준실시간 진행 상태를 제공한다. 초기에는 mock adapter로 이 흐름을 검증한다.
- 강사와 사용자가 허용한 발화자의 음성을 우선 전사/요약 대상으로 한다.
- 주변 대화와 소음은 가능한 한 억제하되, 초기 단계에서 완전한 제거를 보장하지 않는다.
- 무거운 음성인식, 화자 분리와 노트 생성 모델은 클라우드에서 실행한다.
- 세션 종료 후 제목, 핵심 요점, 상세 노트, 미해결 질문/다음 행동을 포함하는 구조화된 강의노트를 생성한다.

### 민감 오디오 수명주기

- 실제 오디오는 인증된 소유자 범위 접근, 비공개 저장소, 만료, 연쇄 삭제가 구현되기 전에는 업로드하지 않는다. 그 전 업로드·통합 테스트는 합성 또는 익명화된 테스트 오디오만 사용한다.
- 성공 처리된 원시 오디오 청크와 임시 AI 산출물은 24시간 안에 삭제한다. 실패하거나 중단된 세션 청크도 마지막 활동 후 24시간 안에 삭제한다.
- 강의 삭제는 남은 원시 청크·임시 산출물·전사문·노트·처리 메타데이터를 즉시 연쇄 삭제한다. 사용자에게 보이는 전사문과 노트는 소유자가 강의를 삭제할 때까지 보존될 수 있다.
- 세션 데이터는 인증된 소유자와 최소 권한 처리 서비스만 접근할 수 있다. 오디오·전사문·노트·서명된 저장소 URL은 로그에 기록하지 않는다.
- 보존 기간은 더 짧게 설정할 수 있어야 하며, 원시 오디오는 무제한 보존하지 않는다.

## 4. 비기능 요구사항과 제약

- 실제 음성 데이터와 개인정보는 최소 수집·최소 보관 원칙을 따른다.
- 클라이언트에 비밀 API 키를 포함하지 않는다.
- Apple Developer 구독, Apple Silicon, 로컬 macOS는 개발·배포 전제조건이 아니다.
- Linux 기반 Codex Cloud에서 자동 검증 가능한 부분은 재현 가능해야 한다.
- iPhone Safari 전용 동작은 실제 기기에서 별도로 검증한다.

## 5. 범위 밖

- 네이티브 iOS 앱 또는 App Store 배포
- iOS의 백그라운드 마이크 녹음을 보장하는 기능
- 온디바이스 대형 음성인식·화자 분리 모델 실행
- 초기 단계의 실제 상용 AI API 연동

## 6. 출시 수용 기준

MVP는 실제 iPhone Safari에서 설치·포그라운드 녹음과 관찰 결과 상태/경고 표시를 검증하고, mock adapter를 통해 청크 업로드부터 준실시간 전사 상태와 종료 후 구조화된 노트 표시까지의 흐름을 시연할 수 있어야 한다. 실제 오디오 업로드는 M1의 최소 개인정보·수명주기 게이트가 충족된 뒤에만 허용한다. 실제 AI 품질, 화자 필터 정확도 및 배포 준비는 이후 마일스톤에서 별도 기준으로 검증한다.
