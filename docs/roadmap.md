# 로드맵

각 항목은 하나의 GitHub Issue와 하나의 PR로 더 작게 분할해 진행한다. 마일스톤 완료는 연결된 실제 검증 결과를 요구한다.

## 현재 구현 및 검증 상태

- M0 마이크/PWA 테스트 하네스와 Linux 자동 검증 workflow를 구현했다. 2026-07-19에 실제 iPhone Safari에서 IOS-01부터 IOS-05까지 실행해 모두 `pass`로 판정했으며, 공식 판정은 [Issue #3](https://github.com/azatos/Repord/issues/3)에 기록했다.
- M0 검증 환경은 앱 버전 `0.1.0`, 커밋 `25a3aa8ccb816b46b695abb78ae1d36b7b0a94b0`, iPhone 15 Pro, iOS 26.5.2, Safari 604.1, 셀룰러 네트워크, 설치형 PWA 및 등록된 service worker다.
- IOS-04와 IOS-05의 `pass`는 앱 전환·화면 잠금 뒤 관찰할 수 없는 구간을 `continuity-unknown`으로 보수적으로 표시했다는 뜻이다. 백그라운드 또는 잠금 화면 녹음의 지속을 보장하지 않는다.
- M1 기반으로 세션·청크 메타데이터 프로토콜 v1을 구현했다. 이는 인증·저장소·업로드·삭제 작업을 구현하거나 M1을 완료한 것이 아니며, 실제 오디오 업로드는 계속 허용하지 않는다. M1 시나리오 IOS-06은 `not-run`이다.
- M2의 mock 전사 UI와 Linux 통합 테스트는 아직 구현하거나 실행하지 않았으며 IOS-07도 `not-run`이다.

## M0 — iPhone Safari 마이크 및 PWA 가능성 검증

- Safari에서 설치 흐름, 마이크 권한, 포그라운드 녹음의 가능성을 실제 기기에서 확인한다.
- 백그라운드/화면 잠금 시 관찰 가능한 연속성 결과와 복귀 동작을 기록한다.
- 완료 상태: 2026-07-19 실제 기기에서 IOS-01부터 IOS-05까지 `pass`. 상세 환경과 판정은 [iPhone Safari 테스트 계획](iphone-safari-test-plan.md)과 [Issue #3](https://github.com/azatos/Repord/issues/3)에 기록되어 있다.

## M1 — 녹음 세션과 청크 업로드

- 세션 수명주기, 순서 있는 오디오 청크, 재시도 가능한 업로드, 연속성 관찰 메타데이터를 정의한다.
- 실제 오디오 업로드 전 최소 개인정보·수명주기 게이트를 구현한다. 이 기준이 모두 통과하기 전에는 실제 오디오 업로드를 비활성화하고, 업로드·통합 테스트에는 합성 또는 익명화된 테스트 오디오만 사용한다.
- 완료 기준: 아래 Linux 자동 검증이 모두 통과해야 M1을 완료할 수 있고 실제 오디오 업로드를 허용할 수 있다.
  - 인증된 소유자 범위 접근과 소유자 간 교차 접근 거부를 검증한다.
  - 비공개 저장소에 공개 객체 접근이 없고, 처리 워커가 최소 권한으로만 접근함을 검증한다.
  - 원시 오디오·전사문·노트·서명된 URL 및 그 밖의 민감 콘텐츠가 로그에서 제외됨을 검증한다.
  - 구성된 보존 기간의 강제, 성공 처리 원시 청크·임시 산출물의 24시간 내 삭제, 실패/중단 세션 청크의 마지막 활동 후 24시간 내 삭제를 검증한다.
  - 강의 삭제 시 원시 청크·임시 산출물·전사문·노트·처리 메타데이터의 연쇄 삭제를 검증한다.
  - 청크 순서, 재시도, 연속성/공백 메타데이터 및 삭제 수명주기 동작을 검증한다.
- 실제 iPhone의 포그라운드 녹음 증거는 위 Linux 개인정보·수명주기·프로토콜 테스트와 별도로 기록하고 검증한다.

## M2 — 실시간 전사

- mock transcription adapter로 준실시간 처리 상태와 부분/완료 전사 흐름을 연결한다.
- 완료 기준: mock 기반 Linux 통합 테스트가 통과하고, 실제 iPhone Safari의 설치된 PWA에서 IOS-07 결과가 `pass`여야 한다. IOS-07 통과 증거에는 iPhone 모델, iOS 버전, Safari 버전, 테스트한 커밋 SHA, 실행 날짜, 테스터와 Linux 자동화와 분리된 실제 기기 증적을 기록한다. `fail`, `blocked`, `not-run`은 M2 완료 기준을 충족하지 않는다.

## M3 — 강사 등록 및 화자 필터링

- 강사 및 허용 발화자 등록, 화자 우선순위, 주변 대화/소음 억제 정책을 설계·구현한다.
- 완료 기준: 합성/익명화된 평가 데이터로 필터 규칙을 검증하고 품질 한계를 문서화한다.

## M4 — 강의노트 생성

- 전사와 화자 메타데이터에서 구조화된 강의노트를 생성한다.
- 완료 기준: mock adapter로 제목·핵심 요점·상세 노트·질문/다음 행동을 포함한 결과 스키마와 오류 상태를 검증한다.

## M5 — 개인정보 보호, 안정화 및 배포

- M1에서 도입한 최소 개인정보·수명주기 제어를 대상으로 최종 보안 검토와 정책 감사를 수행하고, 관측성, 오류 복구, PWA 배포 준비를 완료한다.
- 완료 기준: 보안 검토, 운영 런북, Linux 재현 절차 및 실제 iPhone 회귀 테스트 결과가 준비된다.
