# 로드맵

각 항목은 하나의 GitHub Issue와 하나의 PR로 더 작게 분할해 진행한다. 마일스톤 완료는 연결된 실제 검증 결과를 요구한다.

## M0 — iPhone Safari 마이크 및 PWA 가능성 검증

- Safari에서 설치 흐름, 마이크 권한, 포그라운드 녹음의 가능성을 실제 기기에서 확인한다.
- 백그라운드/화면 잠금 시 중단 양상과 복귀 동작을 기록한다.
- 완료 기준: [iPhone Safari 테스트 계획](iphone-safari-test-plan.md)의 M0 항목에 기기·iOS/Safari 버전·결과가 기록된다.

## M1 — 녹음 세션과 청크 업로드

- 세션 수명주기, 순서 있는 오디오 청크, 재시도 가능한 업로드, 공백 메타데이터를 정의한다.
- 완료 기준: Linux 자동 테스트로 순서·재시도·공백 기록을 검증하고 iPhone에서 포그라운드 녹음을 확인한다.

## M2 — 실시간 전사

- mock transcription adapter로 준실시간 처리 상태와 부분/완료 전사 흐름을 연결한다.
- 완료 기준: mock 기반 통합 테스트와 iPhone UI 흐름 검증을 모두 통과한다.

## M3 — 강사 등록 및 화자 필터링

- 강사 및 허용 발화자 등록, 화자 우선순위, 주변 대화/소음 억제 정책을 설계·구현한다.
- 완료 기준: 합성/익명화된 평가 데이터로 필터 규칙을 검증하고 품질 한계를 문서화한다.

## M4 — 강의노트 생성

- 전사와 화자 메타데이터에서 구조화된 강의노트를 생성한다.
- 완료 기준: mock adapter로 제목·핵심 요점·상세 노트·질문/다음 행동을 포함한 결과 스키마와 오류 상태를 검증한다.

## M5 — 개인정보 보호, 안정화 및 배포

- 보관·삭제·접근 정책, 관측성, 오류 복구, PWA 배포 준비를 완료한다.
- 완료 기준: 보안 검토, 운영 런북, Linux 재현 절차 및 실제 iPhone 회귀 테스트 결과가 준비된다.
